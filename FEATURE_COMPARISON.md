## Selection rationale, not measured rankings

- **Correctness/reliability:** combine A's bounded timestamp-aware ingestion idea, B's public DNG/MediaStore route and C's explicit asynchronous terminal states. None proves IrisI correctness; ownership/timestamp tests are mandatory.
- **UX/accessibility:** use clear start/stop/finalizing and requested-versus-effective values. Do not copy reference layouts/copy or infer accessibility quality from declarations.
- **Resources/compatibility:** a sequential bounded sequence is maintainable in the current Camera2 bridge and has honest limits; proprietary native pipelines cannot be responsibly replicated from these traces. No speed, memory, battery or output-quality winner was measured.
- **Offline/privacy:** local capture needs no reference service. Billing and LUT networking are distinct optional domains, not prerequisites for capture. Reference endpoint/privacy behavior remains incomplete.
- **Unique features retained, not silently dropped:** A diagnostic/install/secure/QS/burst/editor/journal leads; B macro/audio/boost/diagnostics/HDMI and premium gates; C profile/DCP/LUT/import/script/SCREEN/gyro/jobs. Their explicit deferred/unknown mapping is in [traceability](FEATURE_TRACEABILITY_MATRIX.md).
