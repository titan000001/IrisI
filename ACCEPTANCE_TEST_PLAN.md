## Layers and release gate

1. **Host:** isolate state/clock/pairing/ownership/IO behind testable boundaries. Cover both callback orders, all terminal routes and concurrent stop/failure races. No hardware claim from fakes.
2. **Build/static checks:** compile/lint/unit suite, record exact toolchain/dependency failures. Missing wrapper/dependencies mean tests did not execute, not test failures of the feature and never PASS.
3. **Emulator:** permission/navigation/semantics and processed supported paths only. Verify installed package/build identity. Virtual cameras cannot establish physical RAW/HDR/color/cadence performance.
4. **Physical hardware:** RAW-capable supported lens and codec/audio tuples; independently open DNGs/ZIP/video and inspect metadata/images. Record actual count/timestamps/durations/errors and sustained resource behavior without invented throughput thresholds.
5. **P0 sign-off:** AT01–AT13 relevant assertions executed with links, plus AT14 regression. Any BLOCKED hardware assertion remains a published limitation, not a blanket green release. Main audit supplies implementation/file/test mapping. No proprietary parity or exhaustive-discovery gate can be marked passed from this investigation.

IR17–IR23 acceptance is deferred until each family has a precise independent contract and actual implementation. Their presence in reference schemas does not satisfy either requirement or test coverage.
